\section{Classi Target}
% ============================================================

Le due classi target sono state selezionate tramite l'algoritmo della
Milestone 4 del modulo del prof Falessi.

\subsection{BrokerImpl}

\texttt{BrokerImpl} è la classe centrale del kernel di OpenJPA.
Implementa l'interfaccia \texttt{Broker} e gestisce il ciclo di vita
delle entità persistenti: operazioni di persist, merge, remove, find,
query e gestione delle transazioni.
La classe è di dimensioni considerevoli e presenta una complessità
ciclomatica elevata, rendendola un soggetto di testing particolarmente
significativo.

\subsection{LoginDialog}

\texttt{LoginDialog} è un componente dell'applicazione di esempio
OpenTrader, sviluppata con Google Web Toolkit (GWT).
La classe gestisce la finestra di dialogo per l'autenticazione
dell'utente, includendo la logica di validazione dell'input e la
comunicazione con il server tramite RPC.
