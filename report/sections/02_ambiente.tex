\section{Ambiente di Lavoro}
% ============================================================

Il progetto Apache OpenJPA è stato ottenuto tramite fork del repository
ufficiale su GitHub.
Il lavoro si è svolto sul branch \texttt{release-4.1.1}, corrispondente
al tag di rilascio \texttt{4.1.1}.

OpenJPA 4.1.1 supporta Java 11 e versioni successive, come indicato nel
\texttt{pom.xml} del progetto.
Java 17 è stato scelto come versione di riferimento per le operazioni di
build e testing in quanto compatibile con il progetto e privo di problemi
di compilazione; Java 26 causa errori durante la build nel modulo
\texttt{openbooks}.

\subsection{Rimozione dei Test Originali}

Al fine di sostituire interamente la suite di test con quella sviluppata
nel presente progetto, i sorgenti di test originali sono stati rimossi
da tutte le directory \texttt{src/test} dei sottomoduli.

La rimozione dei contenuti di \texttt{src/test} ha reso non valide alcune
\texttt{<execution>} Maven definite nei \texttt{pom.xml} di diversi
sottomoduli.
Tali execution erano legate all'enhancement bytecode delle entità JPA di
test e referenziavano file presenti in \texttt{src/test}.

\begin{itemize}
    \item \textbf{Enhancement tramite Ant} (\texttt{maven-antrun-plugin}):
          diversi moduli eseguivano script Ant,
          i quali cercavano il file \texttt{persistence.xml} in
          \texttt{src/test/resources}; la sua assenza causava un errore.
          Commentando le execution corrispondenti si rimuove l'enhancement
          delle classi di test originali.

    \item \textbf{Enhancement tramite plugin nativo}
          (\texttt{openjpa-maven-plugin}, goal \texttt{test-enhance}):
          alcuni moduli utilizzavano il plugin Maven nativo di OpenJPA
          in sostituzione di Ant per lo stesso scopo.
          Il comportamento e l'errore prodotto sono identici a quelli del
          caso precedente; la soluzione adottata è analoga.

    \item \textbf{Spacchettamento di classi di supporto ai test}
          (\texttt{maven-dependency-plugin}, goal \texttt{unpack}):
          alcuni moduli estraevano classi di utilità per i test originali
          da artifact esterni; con la rimozione di tali test, queste
          execution non sono più necessarie e sono state disabilitate.

    \item \textbf{Build di sotto-progetti di integrazione}
          (\texttt{maven-invoker-plugin}):
          alcuni moduli avviavano build Maven aggiuntivi su sotto-progetti
          dipendenti da risorse di test ora assenti; anche queste execution
          sono state disabilitate.
\end{itemize}

In tutti i casi, l'intervento è limitato al blocco \texttt{<execution>}
del \texttt{pom.xml} del modulo interessato, lasciando invariata la
restante configurazione dei plugin responsabili dell'esecuzione
dei test.
